# Paradise Nursery

A responsive plant-shop web application built with React, Vite, Redux Toolkit, and React Redux.

## Features
- Landing page with a background image and Get Started button
- About Us section
- Plant listings grouped by category
- Add plants to the cart
- Increase/decrease item quantities and remove items
- Cart subtotal and item count
- Responsive layout for desktop and mobile

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.
